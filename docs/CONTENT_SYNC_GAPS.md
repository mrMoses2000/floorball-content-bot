# Пути контента: выпуск 30 сентября 2026

Ранее найденные четыре разрыва закрыты кодом и проверяются PostgreSQL / HTTP тестами:

- trainer → стабильные players / memberships → разрешение имени и биографии → карточки сайта;
- точные поля media.hero/gallery и players.N.photo → worker WebP без EXIF → review →
  media_links / consent → канонические записи → manifest и assets;
- profiles.N.portrait → проверка прав → leadership_profiles → публичный портрет;
- verified/public/current official_documents → metadata + PDF SHA-256 → Documents.

Mini App загружает те же поля, Telegram поддерживает /media и подписи /attach <поле>.
Чужой asset нельзя привязать знанием UUID; необходима ассоциация с текущей анкетой.
Отзыв согласия исключает данные при новом экспорте/публикации. Статический сайт не
читает частную БД на каждый запрос: изменения действуют после проверенного выпуска.
Старые версии анкет сохраняются по hash; новые версии убирают Google Drive URL и
запрашивают постоянные коды игроков и согласие представителя несовершеннолетних.

Google Forms, Apps Script, JSONP и ненастроенный SMTP relay удалены из активной
архитектуры. Отдельная регистрация команды на турнир не реализована; старая форма
и демонстрационный календарь удалены. Анонсы публикуются как проверенные новости.

Статус установки и развёртывания см. PRODUCTION_RELEASE_2026-09-30.md. Проверенный
код сам по себе не означает, что Plesk уже получил конкретную новую сборку.
