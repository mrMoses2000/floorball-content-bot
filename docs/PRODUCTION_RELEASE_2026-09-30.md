# Выпуск: единый сбор контента через Telegram

## Область изменений

Telegram polling и Mini App используют одну PostgreSQL, роли и закреплённые версии
анкет. Новые анкеты trainer.v2/leadership.v2 сохраняют фотографии как управляемые
вложения; старые сессии продолжают использовать свои версии. Миграция 023 добавляет
связь сессии, поля и медиа и расширяет журнал мутаций Mini App. Данные не удаляются.

Утверждённые анкеты обновляют города, клубы, расписания, игроков и тексты федерации.
Изображения публикуются после проверки прав и согласий. PDF сначала сохраняются
приватно, затем просматриваются и утверждаются по UUID и SHA-256. Публикация
использует только проверенные публичные документы и актуальные разрешения.

Publisher собирает публичные JSON и разрешённые файлы в изолированном worktree,
проверяет контракты, собирает сайт и делает снимки. После подтверждения атомарно
обновляет main и plesk-static, вызывает Plesk и проверяет публичные файлы по хешам.
Статус published появляется после проверки фактически доступной сборки.

## Удалено

- Google Forms, Apps Script, JSONP и загрузка публичных Google Sheets.
- Неиспользуемые SMTP/contact API и их обработчик очереди. Применённые миграции
  и исторические таблицы сохранены.
- Неработающие форма контактов, календарь и регистрация турниров. Контакты
  показывают реальные каналы и вход в бот. Регистрация турниров в боте не реализована.

## Эксплуатационные ограничения

Оба Telegram ID 5527988733 и 191148810 активны с ролью superadmin. Telegram
позволяет боту писать пользователю только после начала личного диалога с ботом.
Обнаружено недоставленное напоминание для 191148810 с ошибкой chat not found;
запись сохранена для диагностики, не удалена ради зелёного мониторинга.

floorball.kz/bot/ — HTTPS-вход с перенаправлением на постоянный Tailscale Funnel.
Это не размещение backend на Plesk и не reverse proxy. Бот использует polling.
Systemd и lingering обеспечивают запуск без входа пользователя; полный reboot
сервера в этой работе не выполнялся.

Реальные PDF и профили игроков пока не загружены. Пустые разделы не заполняются
тестовыми сведениями. Отзыв согласия на статическом сайте требует новой публикации
соответствующего раздела. Резервные копии на том же сервере не заменяют внешнюю копию.
