# Google Forms: исторический импорт и отказ от старого канала

Целевая архитектура по решению пользователя: все новые данные собирает Telegram-бот
и его Mini App; PostgreSQL хранит канонические записи. Google Forms, Sheets и
Apps Script не используются как обязательный или резервный канал нового сбора.

CLI import-city/import-federation сохраняется для переноса исторических публичных
bundles и сверки данных. Это совместимость с сохранёнными данными, а не отдельная
рабочая интеграция с Google Forms:

1. Выполнить dry-run импорта и сохранить отчёт.
2. При необходимом переносе применить `--apply`: повтор того же hash не создаёт
   новый snapshot и не меняет revision.
3. Сверить create/update/unchanged/missing_from_source.

В website checkout пока осталась форма регистрации на турниры
`app/src/pages/Tournaments.jsx` с `VITE_GOOGLE_FORMS_WEBHOOK_URL`. Это legacy-код,
который нужно заменить при обновлении сайта; отсутствие webhook не является
причиной настраивать Google Forms заново. У бота пока нет отдельной анкеты
регистрации команды на турнир.

Исторические ответы и существующие импорты не удаляются. Развёртывание сайта
выполняется после завершения проверки бот → БД → утверждение → публичный контент.
